# GTCC Institute for Well-Aging and Lifelong Health

한국어 중심의 정적 교육·참여 안내 사이트입니다. ENG / KOR 버튼은 Google 번역을 사용합니다.

## 로컬 실행
Node.js 20 이상에서 다음 명령을 실행합니다. 미리보기에는 의존성 설치가 필요하지 않습니다.

```powershell
npm run preview
```

브라우저: http://127.0.0.1:4173

## 검사
테스트 도구만 개발 의존성을 사용합니다. Python 3도 필요합니다.

```powershell
npm ci
npm run check
```

자동 검사: 내부 링크·이미지·사이트맵, 이전 콘텐츠 잔존 여부, 상담 양식과 모의 응답, 번역 상태와 오류 처리.
상담 테스트는 실제 Web3Forms로 전송하지 않습니다.

## 구성과 수정
- 루트 HTML 8개: 홈, 연구원 소개, 교육 프로그램, 참여 안내, 연구·협력, 소식·자료, 상담·문의, 사이트맵.
- css/style.css와 js/site.js: 공통 디자인 및 메뉴·번역·상담 기능.
- assets/images: 투명 배경 로고와 심볼 파비콘.
- 공통 헤더·푸터를 변경할 때 모든 HTML에 같은 변경을 반영합니다.
- 소식은 현재 0건입니다. 게시판 생성기는 새 사이트에서 사용하지 않으므로 포함하지 않았습니다.
- 소개와 교육 주제는 검토용 한국어 초안입니다. 확정된 과정·인물·실적·인증·일정·비용을 의미하지 않습니다.

## 외부 서비스
- Google Fonts: Noto Sans KR, 실패 시 시스템 글꼴로 표시됩니다.
- Google 번역: 한국어/영어. 선택을 로컬 저장소에 보관하며 실패 시 한국어로 돌아갑니다.
- Web3Forms: 원본의 공개 access key와 접수 API를 유지합니다. 수신자는 Web3Forms 계정에서 설정되며 새 사이트에서 확인하거나 변경하지 않았습니다. 새 도메인을 서비스에서 허용하는지는 배포 전 확인이 필요합니다.
- 기존 전화·주소·이메일·카카오 링크는 요청에 따라 유지했습니다.
- 접수에는 이름·연락처·이메일·문의 내용을 사용합니다. 비밀키는 저장소에 넣지 않습니다.
